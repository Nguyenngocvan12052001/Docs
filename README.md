# Forknet.io - Developer Docs & Issue Tracking

Welcome to the official repository for **Forknet.io's developer documentation and community issue tracking**.

This repository serves as the central hub for developers building with or on top of the Forknet.io platform. It is not intended for the project's source code, which is located in separate repositories.

## 🎯 Purpose of this Repository

* **Developer Documentation:** The source-of-truth for our technical documentation, guides, tutorials, and API references lives here.
* **Issue Tracking:** A dedicated place to report bugs, request new features, and discuss technical challenges.

## 🚀 Quick Links

* 📖 **[Read the Docs](https://docs.forknet.io)** (Link to your hosted documentation)
* 🐞 **[Report a Bug](./issues/new?template=bug_report.md)**
* 💡 **[Request a Feature](./issues/new?template=feature_request.md)**
* 🔎 **[View Open Issues](./issues)**

## 🤝 Contributing

We welcome contributions from the community! Whether you're fixing a typo in the documentation or reporting a detailed bug, your help is valuable.

* **Documentation:** To suggest changes or add new content, please fork this repository and submit a Pull Request.
* **Issues:** Before submitting a new issue, please search the existing issues to avoid duplicates. Please use the provided templates to ensure you include all necessary information.

For more detailed information, please read our [**Contributing Guidelines**](./CONTRIBUTING.md).
